# Animations

This directory contains the SolidWorks Visualize project files used to create the rendered images and animations for this project.

## Contents

- **v6 engine visualize.svpj** – Visualization project for the complete engine assembly.
- **v6 exploded view visualize.svpj** – Visualization project for the exploded engine assembly.

These files preserve the rendering scenes, materials, lighting, camera positions, and animation settings used throughout the project.
