# CAD Files

This directory contains all CAD assets used in the Digital V6 Engine Replica project.

## Directory Structure

- **assemblies/** – Top-level engine assemblies.
- **subassemblies/** – Intermediate assemblies used to build the complete engine.
- **parts/** – Individual SolidWorks part files organized by engine subsystem.
- **drawings/** – Engineering drawings in both SolidWorks and PDF formats.

All models were developed using SolidWorks and organized following a modular assembly workflow to simplify project management and future modifications.
