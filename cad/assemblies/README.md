# Assemblies

This directory contains the top-level SolidWorks assembly files of the V6 engine project.

## Contents

- **v6 engine.SLDASM** – Complete engine assembly containing all subassemblies and components.
- **upper block assembly.SLDASM** – Upper engine assembly consisting of the cylinder heads, intake system, rocker arm assemblies, and associated components.

These assemblies represent the highest level of the project hierarchy and reference the corresponding subassemblies and part files located throughout the repository.
