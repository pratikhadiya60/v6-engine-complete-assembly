# Subassemblies

This directory contains the intermediate SolidWorks assemblies used to construct the complete V6 engine.

## Available Subassemblies

- **lower block assembly.SLDASM**
- **cylinder head assembly.SLDASM**
- **piston.SLDASM**
- **rocket arm (toolbox).SLDASM**

Each subassembly groups related components into functional modules, making the overall assembly easier to design, modify, and maintain.
