# Images

This directory contains all visual assets used throughout the project documentation.

## Directory Structure

- **renders/** – High-quality images rendered using SolidWorks Visualize for the project showcase and main README.
- **screenshots/** – SolidWorks viewport captures highlighting the assembly, exploded configuration, section views, and other engineering aspects of the project.

The images are separated to distinguish presentation renders from development screenshots, providing both a polished showcase and insight into the CAD design process.
